# `goBasics/structs.go`

[`goBasics/structs.go`](../goBasics/structs.go) defines the `Person` struct with `Name` and `Age` fields. Its value receiver methods, `Greet` and `Eat`, print a greeting and a sentence about the food supplied to `Eat`.

This file is a small example of grouping related data in a struct and defining methods on that type. The methods write directly to standard output and do not modify the `Person` value.
